Argon Dashboard: original vs design tokens

A demo for Screenshot to Tokens (Meta Global AI Developer Hackathon, Metatoy). The same app built twice: once as published, once after replacing 919 hardcoded style values with design tokens.

1. Original Argon Dashboard React as published: hardcoded colors, sizes and spacing. 2. With design tokens Every hardcoded value now reads var(--token, original value), with a three-tier token set (button.bg → color.action.primary → color.blue.500). Colors are unchanged; the small spacing and type clean-up the tokens apply (about 0.9% of pixels) is what a reviewer approves. 3. A proposed change (preview, not merged) The tokenized app with one proposed token value applied live: color.action.primary blue → orange. Every button, toggle and link that uses that token follows. A banner shows the change and a Show original toggle. 4. Token playground (try it) The tokenized app next to its real tokens. Change a color or corner radius and watch the app update live; change a primitive like color.blue.500 and everything aliased to it follows. Nothing is merged; copy a proposal link when you like the result.

Pull request with the token rewrite: nhunsaker/argon-dashboard-react#1 (on this fork only).
